# Руководство администратора

## 📥 Просмотр обращений
Откройте файл базы данных `support.db` в любом SQLite редакторе.  
Таблица `requests` содержит все обращения.

## 📋 Добавление новых FAQ
1. Откройте `faq.json`
2. Добавьте новую пару "вопрос": "ответ"
3. Перезапустите бота

## 🔧 Настройки
- Токен и ID отделов находятся в `config.py`
- Для новых отделов можно добавить ID групп Telegram, куда бот отправляет запросы
